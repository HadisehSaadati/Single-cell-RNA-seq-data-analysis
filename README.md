# Single-cell-RNA-seq-data-analysis
In this project I analyzed single-cell RNA-seq data using an useful package in python for bioinformatics called scanpy.
What I have done:
--> loading data ( contains count matrix, barcodes of cells, and genes)
--> Quality Control (QC)
--> Normalization
--> Finding Highly variable Genes (HVGs)
--> PCA
--> Clustering
--> UMAP
--> Finding marker genes
